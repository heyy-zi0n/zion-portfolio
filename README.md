# Zion-faith Pelumi Omosanya — Portfolio

Minimal, restrained software developer portfolio built with React Router 7.

## Stack
- React 19
- TypeScript
- React Router 7 (framework mode)
- Tailwind CSS 4
- Vite

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Linting / Formatting
```bash
npm run typecheck
```

## Content Management
- Portfolio content and data is centralized in `app/data/portfolio.ts`.
- Project screenshots belong in `public/images/projects/`.
- To add a CV download in the future, place the file at `public/zion-omosanya-cv.pdf` and update the action in `CommandMenu.tsx`.

## Deployment
Compatible with standard React Router / Vite deployment targets.
